4. Geodaten & Wetterabfragen (wetter-site) 4. Geodata & Weather Telemetry (wetter-site)

Im Rahmen der Open-Source-Showcase-Applikation wetter-site wird eine interaktive Wettervisualisierung angeboten:

  • Freiwillige Standortermittlung: Die Abfrage der Koordinaten über die HTML5 Geolocation API erfolgt ausschließlich nach Ihrer ausdrücklichen Freigabe im Browser (Art. 6 Abs. 1 lit. a DSGVO). Alternativ steht eine manuelle Stadtsuche ohne GPS-Zugriff bereit.
  • Kein Server-Tracking: Es erfolgt zu keinem Zeitpunkt eine serverseitige Erfassung, Protokollierung oder Speicherung Ihrer Geokoordinaten oder Bewegungsprofile durch Jeremy Benz.
  • Verschlüsselte API-Abfrage: Die Wetterabfrage erfolgt rein clientseitig aus Ihrem Browser direkt an die datenschutzfreundliche API von Open-Meteo (Open-Meteo GmbH, Deutschland) über verschlüsseltes HTTPS. Die API verlangt keine Registrierung und erzeugt keine Verhaltensprofile.

The open-source showcase web app wetter-site provides interactive weather telemetry:

  • Voluntary Geolocation: Browser coordinate lookups via HTML5 Geolocation API execute only upon your explicit browser permission (Art. 6 (1) lit. a GDPR). A manual city search is available without GPS coordinates.
  • Zero Server Tracking: At no point does Jeremy Benz capture, log, or persist your geographical coordinates or location telemetry on any server.
  • Encrypted Client API: Telemetry calls are dispatched directly from your browser client to the privacy-respecting API of Open-Meteo (Open-Meteo GmbH, Germany) over encrypted HTTPS. The API requires no registration and builds zero behavior profiles.

Diese Website verwendet bewusst keine externen Google Fonts oder ungeschützten Fremd-CDNs. Es werden ausnahmslos systemeigene Schriftarten Ihres Endgeräts (System UI, San Francisco, Segoe UI, Roboto) geladen.

This website deliberately avoids all external Google Fonts or untrusted CDN relays. Typography is rendered purely with your operating system's native font stacks (System UI, San Francisco, Segoe UI, Roboto).
