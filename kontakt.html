🛡️ Responsible Disclosure 🛡️ Responsible Disclosure

Hast du eine Sicherheitslücke in einem meiner Open-Source-Projekte gefunden?

  • Kein öffentliches Issue: Bitte niemals Zero-Day-Lücken öffentlich auf GitHub melden.
  • Format: Sende Details an benzjeremy@pm.me mit dem Betreff:
    [SECURITY] [PROJEKTNAME] [KURZBESCHREIBUNG]
  • Garantie: Erste Sichtung und Rückmeldung innerhalb von 48 Stunden.

Found a vulnerability in any of my open-source projects?

  • No Public Issues: Never disclose sensitive flaws in public GitHub issues.
  • Subject Format: Email benzjeremy@pm.me with subject:
    [SECURITY] [PROJECT] [BRIEF SUMMARY]
  • Guarantee: Initial triage and response within 48 hours.
