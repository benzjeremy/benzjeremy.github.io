System & Cloud-Infrastruktur

docklite

Eine radikal schlanke, sichere Portainer-Alternative in Go und Astro. Löst das Problem schwerfälliger Container-Management-Tools, die 250+ MB RAM fressen: Docklite benötigt lediglich 10–15 MB RAM, kommuniziert nativ mit dem Docker-Socket (docker.sock / Named Pipe), liefert Echtzeit-Statistiken via Server-Sent Events (SSE), bietet vollständige Container-Lifecycle-Kontrolle und bettet das Astro-Dashboard direkt als Single-Binary ein.

Go Astro Docker docker.sock REST API SSE Linux Windows GPL-3.0

System & Cloud Infrastructure

docklite

An ultra-lightweight, secure Portainer alternative written in Go and Astro. Solves the bloat problem of traditional container management tools that consume 250+ MB of RAM: Docklite runs with just 10–15 MB of RAM, speaks directly to the Docker socket (docker.sock / Windows Named Pipe), streams live container metrics via Server-Sent Events (SSE), provides full container lifecycle control, and bundles the Astro dashboard into a single standalone binary.

Go Astro Docker docker.sock REST API SSE Linux Windows GPL-3.0
